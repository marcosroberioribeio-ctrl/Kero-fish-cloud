# Kero Fish ERP Premium V12

Versão premium do ERP da Kero Fish, com integração entre compras, estoque, vendas, financeiro, contas a pagar/receber, entregas, relatórios, auditoria, importação e backup.

A base inicial é reconstruída automaticamente a partir dos dados oficiais da planilha atualizada enviada em 28/08/2026. A importação é idempotente para evitar duplicidades.

Identidade visual: Kero Fish — PEIXE E CAMARÃO.

Arquivo principal: `app.py`

Dependências: Streamlit, pandas e openpyxl.
